# 🎓 Student Management System

A console-based **Student Management System** developed using **Java, JDBC, and MySQL**.

---

## 📌 Features

- ➕ Add Student
- 📋 View All Students
- 🔍 Search Student
- ✏️ Update Student
- 🗑️ Delete Student

---

## 🛠️ Technologies Used

- Java
- JDBC
- MySQL
- Eclipse IDE
- Git
- GitHub

## 🗄️ Database

Database Name

```sql
student_management
```

Table

```sql
students
```

Columns

- student_id
- name
- department
- semester
- email
- phone_number

---

## ▶️ How to Run

1. Clone this repository.
2. Open the project in Eclipse.
3. Create the MySQL database.
4. Update your database username and password in `DBConnection.java`.
5. Run `App.java`.
